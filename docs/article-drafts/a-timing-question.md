# A Timing Question

> Platform work is not a component question. It is a timing question: pay once centrally now, or N times locally forever — plus interest, charged as drift.

**Description.** How to argue for foundation work to people who fund features. The pitch that works reframes the decision: the shared path will exist either way — the only choice is whether it exists once, deliberately, or five times, accidentally, one per team. Each local version costs its team the same setup; the versions then diverge, and the divergence itself becomes a permanent tax on every future change. The window to shape the shared path closes quietly, team by team.

**Why it lands.** Every platform-minded engineer has lost this argument by making it about quality ("our way is better") or aesthetics ("consistency matters") — both lose to a feature deadline. The timing frame wins because it concedes the ground that doesn't matter (teams *can* build it locally, sure) and claims the ground that does: the cost curve. This is the essay version of a pitch that has to be made in every growing org, written so readers can adapt it rather than rediscover it.

## Outline

1. **The losing arguments.** Quality, consistency, elegance — all true, all defeated by "the feature ships Friday." Platform arguments fail when they compete with features on features' terms.
2. **The reframe.** Nobody is choosing *whether* the capability exists. Every team needs auth wiring, form handling, telemetry, the design system's glue. The choice on the table is only: one shared shape now, or one shape per team as each hits the need.
3. **The cost model.** N local versions cost N setups (linear, visible) and then divergence (compounding, invisible): every upgrade, audit, and hire now meets N variants. Drift is the interest rate on deferred platform work.
4. **Timing is the argument.** Early, the shared path is cheap to shape — nothing to migrate, no habits to break. Late, it's a migration project competing with everything. The option expires while everyone agrees it's a good idea.
5. **Make the right thing the easy thing.** The platform's obligation in return: the shared path must be genuinely easier than local — less setup, less plumbing, escape hatches preserved. A paved road, not a toll road. Adoption is the proof; mandates are the confession.
6. **Ask for direction, not applause.** The close of the pitch matters: not "declare this finished" but "support the direction and let it mature." Small ask, hard to refuse, and it keeps the platform honest about its own immaturity.
7. **Close.** You are not asking for budget to build a thing. You are asking to build it once.
